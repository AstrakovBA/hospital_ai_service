# ADR-002: GigaChat как основной LLM-провайдер

## Статус
Принято

## Контекст
Медицинская информационная система развёрнута в РФ.
Требуется LLM с поддержкой русского языка и соответствием 152-ФЗ.

## Решение
Основной провайдер: GigaChat (SberCloud).
Fallback: InternalLlmClient (шаблонные ответы).

## Обоснование
- Данные не покидают территорию РФ
- Поддержка русского языка
- Корпоративный API с SLA
- Возможность развёртывания в контуре организации (будущее)

## Риски
- Стоимость запросов
- Ограничение на длину контекста
- Зависимость от доступности SberCloud
