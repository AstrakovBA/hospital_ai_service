# ADR-001: Использование паттерна AI Gateway

## Статус
Принято

## Контекст
Сервис интегрируется с LLM-провайдером (GigaChat). Прямая интеграция создаёт:
- Vendor lock на конкретного провайдера
- Невозможность централизованного управления (квоты, логирование, метрики)
- Распределение вызовов LLM по кодовой базе

## Решение
Ввести слой `AiGateway` как единую точку доступа к LLM.
Бизнес-логика работает только через интерфейс `LlmClient`.

## Последствия
+ Переключение провайдера без изменения бизнес-логики
+ Централизованные метрики, логирование, fallback
+ Возможность A/B тестирования моделей
- Дополнительный слой абстракции (незначительная сложность)
